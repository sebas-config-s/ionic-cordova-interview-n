Configuración Firebase Remote Config Feature flags en tiempo real y/o al recargar la App Remote Config permite activar o desactivar funcionalidades sin publicar una nueva versión de la app. El valor se obtiene desde Firebase y se aplica instantáneamente. En este caso se utiliza para mostrar u ocultar las estadísticas de tareas. El flag show_statistics se puede cambiar desde la consola de Firebase y la app reflejará el cambio en tiempo real al recargarla.
